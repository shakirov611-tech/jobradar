# Персональный подбор и оценка качества — v0.7.0

## Запуск

Обновите файлы проекта в прежней папке, сохранив .env.integration и .collector-state. n8n и Docker для read-only обзора не нужны; .env.integration используется для прежних overrides конфигурации, запросов к n8n нет.

```powershell
npm.cmd run matching:review -- --open
```

Команда читает публичные источники и открывает до 24 вакансий в браузере. Отметьте «Подходит / Не подходит / Уточнить», при необходимости укажите причину. Решение алгоритма спрятано в details, чтобы можно было сначала оценить самостоятельно. Нажмите «Скачать оценки JSON». Файл можно передать для разбора или посчитать отчёт самостоятельно:

```powershell
npm.cmd run matching:report -- "C:\Users\Denis\Downloads\jobradar-labels-XXXXXXXXXXXX.json"
```

Замените путь фактическим скачанным файлом. Отчёт сохраняется рядом с исходным snapshot и выводится в консоль. Он не записывает оценки в CRM. Для внешнего разбора конкретных вакансий приложите также соответствующий `.collector-state/review-<snapshotId>.json`: файл оценок содержит ID и отметки, но не полный текст вакансий. Для основного каталога: `npm.cmd run collector:preview -- --open`; в нём также есть ссылка на контрольную выборку.

Каждый снимок хранится в .collector-state/review-<snapshotId>.json и .html. Повторный сбор создаёт другой снимок; старые файлы сохраняются. Чтобы продолжить разметку, откройте прежний HTML. Не удаляйте исходный JSON до расчёта отчёта. Черновик сохраняется в localStorage только если браузер разрешает его для локальных файлов; экспорт JSON — переносимая копия. Импорт принимается только для соответствующего снимка. Отсутствие оценки и «Уточнить» не считаются отказом.

## Профиль

В config/search-profile.json добавлен блок matching. Primary: product/growth/product_owner; secondary: delivery. Предпочтительные уровни senior/lead/head и язык команды ru — мягкие предпочтения. Их можно изменить; это не подтверждение квалификации кандидата. Remote-only и текущая страна BG определяют проверку явных противоречий. Поддержка других стран требует отдельного расширения правил.

Результаты: priority («Сначала посмотреть»), review («Нужно уточнить»), excluded («Есть противоречие»). Нет процентного score. Priority означает приоритетное направление + предпочитаемый уровень в названии + remote, без обнаруженных противоречий/мягких расхождений. Неизвестные условия найма и требования к опыту остаются видны даже у priority.

Уровень распознаётся по названию, а не по придуманному количеству лет опыта. Явные требования языка и язык команды — разные сигналы. Англоязычное описание не доказывает англоязычную команду; русскоязычные клиенты не доказывают русский рабочий язык. Языковая способность кандидата не угадывается. Шаблоны ограничены; нераспознанное остаётся unknown.

Устаревшие local profile-файлы без matching продолжают работать как unconfigured/review. Для включения персонализации обновите используемый профиль, включая путь из JR_SEARCH_PROFILE_FILE если он настроен. CRM rows не меняются из-за персональных предпочтений: ID, first_seen/last_seen, статус и заметки сохранены.

## Что измеряется

Выборка детерминированна для одного снимка: группы main/unclear/excluded/other_roles чередуются, внутри групп чередуются компании/источники. Если групп мало, свободные места заполняются доступными. Дубликаты vacancy_id не допускаются. Это диагностическая выборка, не случайная репрезентативная выборка рынка.

Матрица сопоставляет решения алгоритма с ручными suitable/unsuitable/uncertain; показывает priorityRejected и excludedButUseful. Unknown и пропущенные оценки учитываются отдельно. До разметки точность и полезность не заявляются. Ссылка на оригинал помогает проверить актуальность; снимок не означает, что вакансия ещё открыта после момента сбора.

## Проверки и ограничения

Автотесты покрывают приоритеты/противоречия/unknown, профиль и совместимость CRM, обе ATS, баланс выборки, привязку оценок и XSS. Браузерные тесты проверяют фильтры, reload/autosave, экспорт, импорт и отказ чужому snapshot.
Правила формата/страны из v0.6.1 сохранены с известными эвристическими ограничениями. Опыт, навыки, домен, зарплата, полная занятость, право на работу и персональное соответствие ещё не подтверждаются. Текст для анализа ограничен 120000 символами, текст review-карточки — 12000 с отметкой усечения. Источники могут ошибаться; partial виден в обзоре. Рабочий n8n из облака не проверялся.
