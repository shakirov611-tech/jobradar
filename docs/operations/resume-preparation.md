# Подготовка резюме — DOC-01, первая итерация

Работает локально, Node.js >=22; n8n запускать не нужно. Основа принята пользователем и слита в PR #15. Опубликованный v0.7.1 команды не содержит.

1. Сохраните подготовленный приватный JSON фактов в `config/private/candidate-facts.json`. Папка игнорируется Git. Не используйте в ней публичные fixtures.
2. Возьмите JSON снимка из `.collector-state/review-<id>.json`; ID выбранной вакансии — поле `vacancy_id` в `items`. Также поддерживается `catalog` или JSON одной вакансии. HTML подборки не является входным JSON.
3. В PowerShell в каталоге проекта:

```powershell
npm.cmd run resume:prepare -- "config/private/candidate-facts.json" ".collector-state/review-<id>.json" "vacancy_id" --open
```

Замените `<id>` и `vacancy_id` фактическими значениями. Команда откроет локальный review; при невозможности открытия путь выводится в консоль. Исходные файлы не меняются.

Просмотрите контакты и названия ролей. Подтверждённые факты выбраны заранее. Остальные доступные факты выбирайте только если подтверждаете их для этого резюме. Спорные, заменённые и скрытые сведения недоступны. По каждому пункту показан источник. Совпадение слов определяет порядок, но не доказывает соответствие вакансии.

Поставьте «Я проверил…» и скачайте резюме HTML. При необходимости отдельно скачайте запись проверки JSON. Резюме не содержит исходных цитат и скрытых фактов. Откройте скачанное HTML → Ctrl+P → Сохранить как PDF. Проверьте страницы и контакты перед использованием. Это не автоматический проверенный PDF renderer.

Review содержит персональные данные. Пакеты находятся в `exports-private/resumes/<hash>/`; повтор одинаковых входов даёт тот же путь. Изменение профиля/вакансии создаёт другую версию. Выбор автоматически сохраняется в localStorage, если браузер разрешает это для локального файла. Для переноса используйте «Скачать черновик JSON» и «Загрузить черновик». Файл проверяется целиком до изменения выбора; другой профиль или вакансия отклоняются. После восстановления подтверждение экспорта сбрасывается. Пустой выбор можно сохранить, но нельзя экспортировать как резюме. Никаких API-ключей/LLM или отправки отклика нет.

## Проверки

`npm.cmd run check` — схема, approval gate, provenance, блокировка заменённых фактов, диапазоны, версии, escaping, локальный CLI. `npm.cmd run test:browser` после `npm.cmd run browser:setup` проверяет выбор, сброс approval и содержимое HTML/JSON download на синтетическом профиле. Реальный профиль в CI не используется.

## Каталог → резюме

Если профиль лежит в `config/private/candidate-facts.json`, `npm.cmd run collector:preview -- --open` добавляет ссылки «Подготовить резюме» к вакансиям, прошедшим фильтр ролей. Профиль не встраивается в каталог; ссылки ведут к приватным локальным пакетам. При ошибке профиля каталог остаётся доступен без этих ссылок.

Без повторного сбора: `npm.cmd run resume:catalog -- config/private/candidate-facts.json .collector-state/preview.json`. Откройте выведенный путь. Можно передать и review JSON с items. Каталог и exports-private должны оставаться в исходной структуре папок.

Предпросмотр обновляется при выборе фактов; его содержимое и HTML export используют один renderer. AI-перефразирование и автоматический PDF пока не реализованы.
