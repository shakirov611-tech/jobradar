## Обновление

Скопировать файлы выпуска в прежнюю папку проекта, сохранив `.env.integration` и `.collector-state`.
Запустить `npm.cmd run collector:preview -- --open`.
Новые ключи, столбцы CRM и переустановка расписания не требуются.

## Ограничения

Фильтр использует языковые эвристики. Remote не подтверждает возможность найма из Болгарии;
язык команды и разрешение на работу остаются непроверенными. Фильтруется HTML обзор, не CRM.
