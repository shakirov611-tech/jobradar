# v0.7.0 — Персональный подбор и проверка качества

## Изменения

- Профиль приоритетных и дополнительных направлений, уровней и языка команды.
- Объяснения: совпадения, различия, противоречия и неизвестные условия; порядок просмотра без процента fit.
- Read-only выборка до 24 вакансий из разных групп/компаний; оценки в браузере с JSON export/import.
- Проверка соответствия оценок исходному снимку и отчёт с отдельным учётом uncertain/unlabeled.
- Включены ESLint/config gates из PR #12; рабочие данные Google Sheets не меняются.

## Обновление

Замените файлы проекта в прежней папке, сохранив .env.integration и .collector-state. Запустите `npm.cmd run matching:review -- --open`. Отметьте вакансии и нажмите «Скачать оценки JSON».
Настройка n8n и расписания не требуется. Если используется собственный JR_SEARCH_PROFILE_FILE, добавьте matching блок в него по config/search-profile.json.

## Проверки и границы

113 Node-тестов проходят локально. Перед публикацией обязательны успешные CI и браузерные проверки на commit выпуска.
Read-only smoke: 754 raw вакансии, 53 ролевых кандидата, выборка 24, шесть компаний; это результат одного наблюдения 2026-10-29, не показатель качества подбора.
Разметка пользователем ещё не выполнена. Персональная полезность не измерена. Remote не гарантирует найм из BG; фактический опыт/языковая способность/зарплата не проверены. Локальный n8n в этом изменении из облака не запускался.
