# v0.8.0 — Языковой подбор и подготовка резюме

## Изменения

- Язык публикации, язык команды и языковые требования анализируются отдельно, с цитатами и статусом достоверности. Неизвестный язык не исключает вакансию из общего каталога или CRM.
- Персональные предпочтения и уровни кандидата влияют на Language Fit независимо от общего анализа. Языки настраиваются через конфигурацию; русского глобального фильтра нет.
- Общий кэш учитывает текст и версии алгоритма/промпта. Rules работают без ключа; optional AI использует JSON schema, ограниченные попытки, timeout и бюджет. При ошибке вакансия сохраняется.
- Языковые пояснения доступны в HTML-каталоге. Две новые JSON-колонки Sheets включаются отдельно и проверяются чтением после записи. Ручные поправки привязаны к вакансии и хешу её текста.
- В выпуск включены подготовка резюме из приватных фактов, проверка состава перед HTML export, черновики с JSON import/export, предпросмотр и переход из каталога (PR #15–16).
- Обновлены инструкции AI-разработки, карта кода, архитектура, Data Contract, ADR 015, roadmap и backlog. Новых зависимостей нет.

## Обновление на Windows

Скачайте **Source code (zip)** со страницы v0.8.0 в GitHub Releases. Обновите исходники в прежней папке проекта, где находится `package.json`. Сохраните `.env.integration`, `.collector-state`, `config/private`, `exports-private`, свои настройки и JSON оценок/черновиков. Не заменяйте весь каталог удалением: эти локальные данные отсутствуют в архиве. При Git-установке сначала сохраните собственные изменения и обновитесь до тега `v0.8.0`.

Проверьте языковые предпочтения и уровни в `config/search-profile.json` либо своём `JR_SEARCH_PROFILE_FILE`: пример первого пользователя не является подтверждением актуального уровня. Собственный профиль без нового блока продолжает работать, но не даёт полной проверки уровней языка. Затем из папки с `package.json`:

```powershell
node -p "require('./package.json').version"
npm.cmd run collector:preview -- --open
```

Ожидаемая версия — `0.8.0`. Preview не вызывает n8n и не записывает Google Sheets. Языковые пояснения появятся в новой подборке; старые снимки сохраняются. Для локальных тестов: `npm.cmd ci --ignore-scripts --no-audit --no-fund`, затем `npm.cmd run check`.

По умолчанию новые колонки Sheets выключены. Для включения следуйте [порядку проверки и миграции](../operations/language-intelligence.md#локальная-проверка-и-crm): добавить только отсутствующие заголовки в тестовой таблице → `collector:test` с флагом текущего PowerShell → проверить результат → подготовить рабочие заголовки → включить постоянный флаг. Существующий `language` не переименовывать, дубли колонок не создавать. Генератор workflow обновится из кода; переустановка Docker, n8n и Windows task не нужна, если путь к проекту сохранён.

Подготовка резюме и сохранение черновиков: [инструкция](../operations/resume-preparation.md). Реальные факты остаются в приватном локальном JSON; релиз их не содержит.

## Проверки и границы

На коде Language Intelligence `dbaccb2` прошли [161 Node-тест, ESLint и config contracts](https://github.com/shakirov611-tech/jobradar/actions/runs/41876856051) и [13 browser fixtures](https://github.com/shakirov611-tech/jobradar/actions/runs/41876856015). Финальные проверки версии выполняются в [PR #18](https://github.com/shakirov611-tech/jobradar/pull/18/checks); точный тег и итоговый commit указаны на странице Release.

Сбор, dedup, first/last_seen, ручные поля и отключённый по умолчанию CRM opt-in покрыты fixtures. **Локальный n8n/Sheets с новыми колонками и реальный AI-провайдер из облака не проверялись.** Качество классификации на рынке не измерено; rules распознают ограниченный набор формулировок, прочее требует уточнения. Адаптивный выбор источников и применение company/team signals отложены. LLM professional matching, автоматический PDF и реальные автоотклики не входят в эту версию.

Release не обновляет ПК автоматически. Откат языковых колонок: убрать `JR_LANGUAGE_SHEETS=1`; уже записанные значения останутся историческими. При возврате к v0.7.1 также вернуть совместимую конфигурацию профиля: старая версия не знает `personal-match-v2` и новых настроек. Ключи, приватные факты и локальные снимки сохранять; ранее опубликованные теги не менять.
