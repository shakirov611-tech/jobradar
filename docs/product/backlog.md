## Ближайшая итерация MATCH-01

- Готово: профиль ролей, уровня, географии и предпочтительного языка команды; неизвестное хранится явно.
- Готово: remote, доступность найма из страны и язык команды разделены.
- Готово: объяснения и простая разметка «подходит / не подходит / уточнить».
- Следующее: пользователь оценивает фиксированную выборку до 24 вакансий из разных групп; проверяем также ложный отсев.
- Установить порог качества после разметки; результаты должны воспроизводиться на fixtures.
- Сохранить ID, даты и ручные поля CRM. Не переносить фильтр обзора на writer неявно.

## Доказательства и незакрытые проверки

Код v0.7.0 проверен: 113 Node + 7 browser tests, CI успешен. Пользователь подтвердил v0.4 integration и первый scheduled production v0.5.
Установка v0.6.1 и отдельный multi-source runtime test пока не зафиксированы доказательствами.
Remote evidence и main/unclear/excluded реализованы только для обзора; персональный matching ещё не измерен.
Язык команды, seniority, домен, зарплата и право на работу не считаются автоматически подтверждёнными.
Реальных отправок работодателям не было; browser DOM inspection не равен успешному upload или Submit.

## Границы

Генерация резюме и автоотклики входят в core scope. Сейчас не вводим Kubernetes, микросервисы,
массовый scraping LinkedIn, LLM scoring без benchmark и billing без pilot evidence.
Старые JR-ID сохранены для трассировки; исторические редакции доступны в Git.

## Уточнение приоритета: CI перед MATCH-01

По решению пользователя сначала усилены автоматические проверки: ESLint, JSON/config contracts и PR CI.
[Инструкция и ограничения](../operations/ci.md). Реальный n8n/Sheets остаётся локальной проверкой; обязательность checks через branch ruleset отдельно не настроена. Усиление CI выполнено, работа вернулась к MATCH-01.

## MATCH-01 v0.7.0: следующий конкретный шаг

Оценить контрольную выборку в локальном HTML и экспортировать JSON. CLI отчёт проверяет привязку снимка/профиля и показывает матрицу решений. Качество не заявлять до разметки; потребность в LLM, более широких country/language rules и новых источниках определить по ошибкам. Шаблонные правила не сравнивают опыт кандидата с требованиями; домен, навыки, зарплата и занятость остаются unknown.
