# ADR 006 — Воспроизводимость до роста

Дата: 2026-10-29. Статус: Accepted for design. Владелец решения: владелец JobRadar.

## Контекст
Плавающий stable, нет restore evidence и окончательного SaaS UX.

## Решение
До обновлений фиксировать image version/digest и делать tested backup; до коммерческого pilot проверить применимость лицензии n8n к реальному UX.

## Альтернативы
Сразу обновить образ или объявить лицензию подходящей без проверки сценария.

## Последствия
Нужна локальная работа и отдельный licensing checkpoint; текущая установка не меняется.

## Пересмотр
При смене deployment или функциональности пользовательских автоматизаций.

## Уточнение 2026-10-29

Пользователь явно отложил backup/restore ради скорости обратимых изменений collector.
Это не gate для текущих v0.4/v0.5; Docker image, volume и OAuth не изменяются.
Вернуться к backup/restore перед обновлением инфраструктуры или вторым пользователем.
