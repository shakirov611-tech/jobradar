# ADR 001 — Сохранить действующий стек

Дата: 2026-10-29. Статус: Accepted for design. Владелец решения: владелец JobRadar.

## Контекст
Есть работающий single-user pipeline, но нет воспроизводимого экспорта.

## Решение
Оставить локальный n8n + Greenhouse + JS + Sheets до Baseline gate. Извлекать код и contracts без смены поведения.

## Альтернативы
Полная перепись и немедленная PostgreSQL migration увеличивают риск без подтверждённой потребности.

## Последствия
Сохраняется ручной CRM интерфейс; ограничение Sheets concurrency остаётся и должно быть проверено.

## Пересмотр
Перед вторым пользователем либо измеренным конфликтом записи.
