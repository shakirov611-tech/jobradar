# ADR 003 — Сохранить локальную границу

Дата: 2026-10-29. Статус: Accepted for design. Владелец решения: владелец JobRadar.

## Контекст
localhost пользователя недоступен из облака.

## Решение
Аудит по санитизированным экспортам и локальным свидетельствам; не открывать n8n и не создавать туннель.

## Альтернативы
Прямое подключение удобнее, но меняет инфраструктуру без необходимости.

## Последствия
Некоторые выводы остаются неподтверждёнными до локальной проверки.

## Пересмотр
Если отдельно согласована hosted architecture с auth и monitoring.
