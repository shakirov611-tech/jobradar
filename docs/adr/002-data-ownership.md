# ADR 002 — Отделить каталог от личного CRM

Дата: 2026-10-29. Статус: Proposed. Владелец решения: владелец JobRadar.

## Контекст
Vacancy — общая сущность; заметки, профиль и решения — личные.

## Решение
Для pilot проектировать общий каталог и user-scoped profiles, matches, CRM в продуктовой PostgreSQL. Не использовать внутренние таблицы n8n.

## Альтернативы
Отдельный Sheets на каждого прост, но плодит сборы и sync; общая таблица с user_id не обеспечивает доступ.

## Последствия
Потребуются auth, миграция, cross-user tests и ownership rules; сейчас DB не разворачивается.

## Пересмотр
После исследования pilot: возможно потребуется organization tenancy.
