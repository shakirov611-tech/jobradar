# ADR 005 — Один источник конфигурации

Дата: 2026-10-29. Статус: Proposed. Владелец решения: владелец JobRadar.

## Контекст
E2 отключает Greenhouse вопреки работающему flow.

## Решение
Сначала установить runtime truth. Затем версионированная конфигурация источников вне workflow; secrets отдельно; профиль кандидата отдельно. Schema version и явная загрузка обязательны.

## Альтернативы
Пока всё в nodes проще, но расходится с JSON; DB config преждевременен.

## Последствия
Не включать E2 автоматически: может остановить сбор; миграция настроек отдельным PR.

## Пересмотр
Перед UI onboarding конфигурация профилей может перейти в product DB.
