# ADR 011 — Подтверждённый remote для основного списка

Дата: 2026-10-29. Статус: Accepted, пользователь согласовал правило.

## Контекст

Одна географическая локация не объясняет формат работы; неизвестное засоряет основную
выдачу. Прежняя v0.6 анализировала только структурные location/workplace и показывала
всех role candidates по умолчанию. Пользователь хочет убрать вакансии без remote.

## Решение

Учитываем описание и поля. Main требует remote evidence и отсутствия выявленного
ограничения страны. Unknown/conflicting → unclear, onsite/mandatory hybrid/restricted →
excluded. Все группы остаются доступны; evidence/reason показываются явно.
Не меняем ownership CRM или last_seen: collector пишет прежний role catalog, фильтр
касается основного HTML view. Отдельные views counts не переименовываются в role matched.

## Последствия

Чище основной список без удаления данных. Keyword policy не гарантирует eligibility
или полноту распознавания. Нужна пользовательская разметка качества; не включаем LLM
и не считаем отсутствие remote доказательством onsite. [Операции](../operations/remote-view-v0.6.1.md).
