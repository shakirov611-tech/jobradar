# ADR 014 — Локальное резюме из фактов

Дата: 2026-11-03. Статус: Accepted for first iteration.

## Контекст

После v0.7.1 пользователь отметил улучшение подбора и разрешил переход к D. Это качественная обратная связь, а не новая измеренная точность. Четыре CV сведены в приватный черновик фактов; даты, контакты, языки, позиционирование и метрики уточнены пользователем.

## Решение

Первая итерация DOC-01 не использует LLM и новые runtime dependencies. CLI читает локальный профиль и выбранную вакансию из items/catalog либо отдельной записи. Создаёт пакет и автономный HTML review в игнорируемом exports-private/resumes. Никаких обращений к n8n, Sheets или работодателю.

Контракт импорта: jobradar-candidate-facts-draft, schema_version=1. Каждый факт имеет ID, subject, field, value, статус, source_refs и approved_for_generation. Подтверждение пользователем не означает независимую проверку. Только confirmed с явным approval включается заранее. Imported/needs_context можно подтвердить выбором для конкретного документа. Conflicting/superseded/not_selected и скрытый cofounder заблокированы. Приватные исходники и профиль никогда не включаются в fixtures/CI.

Адаптация ограничена порядком фактов по совпадению слов, ручным отбором и заранее согласованными названиями ролей. Это не semantic matching и не генерация новых утверждений. Формулировки и диапазоны сохраняются. Предпочтение большего значения не разрешает объединять разные определения, периоды или единицы; импорт не выполняет такой выбор автоматически.

SHA-256 связывает пакет с полным профилем, выбранной вакансией и результатом подготовки. Review показывает исходные цитаты и включение/исключение. Экспорт требует подтверждения; изменение выбора сбрасывает подтверждение. Импортированный факт, выбранный для документа, не меняет исходную базу. Отдельный JSON фиксирует выбор и хеши, но не является разрешением на отправку.

## Ограничения

HTML export — первый текстовый шаблон; PDF сохраняется через печать браузера. DOCX, перевод/перефразирование, редактирование текста, автоматическое сохранение выбора, импорт review manifest и автоматический PDF ещё не реализованы. Контроль состава — diff выбора фактов, не line-by-line diff с исходным DOCX. Stage D не завершён, релиз не выпущен. DB и approval отправки остаются отдельным этапом до E.
